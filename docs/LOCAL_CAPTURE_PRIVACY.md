# 本地页面采集：隐私与来源契约

2026-09-24。本轮完成独立的**元数据过滤与延迟读取契约**，不等于已经能够采集真实页面。实现位于 `ocrlab` 的 `context/capture/LocalCapturePrivacy.kt`，没有正式放大镜、无障碍服务、OCR 或联网调用入口。

## 本轮做成了什么

1. 首先接收不含正文的窗口/节点元数据，完整验证有界结构；仅对满足当前规则的节点调用文字读取回调。密码、敏感节点、可编辑内容、未知隐私证据及非目标窗口在取文字前排除。
2. 保留整页可用叶节点的原文、父节点 ID、窗口 ID、原始/可见位置、原阅读顺序、角色及 text/contentDescription 来源，没有 ROI 参数。框外标题和限制条件不会因为离开选区而被裁掉。
3. 排除密码等节点的后代；容器或有子节点的汇总标签不读取，防止从父节点重新拿到已排除的子节点内容。安全兄弟叶节点仍可保留。
4. `YES / NO / UNKNOWN / UNAVAILABLE` 分开。未知和接口不支持不被转换成 `NO`。目标窗口不明确、多目标或窗口枚举不完整时整次拒绝；节点枚举不完整仍可保留已确认的片段，同时保留原枚举状态。
5. 获取前、每个节点前、文字获取后和返回前均核对会话/快照/页面/内容/窗口/显示器版本、激活状态和单调时钟。失效时整批返回空，不留下部分结果。函数自身不缓存；未来调用方仍须在结果返回后负责失效和释放引用。

输出为独立的 `LocalCaptureInspection`，不能直接当作 `ScreenSnapshot` 或网络请求。来源固定 `SYNTHETIC_METADATA`，覆盖程度始终 `UNVERIFIED`；不存在“所有节点通过，所以整个页面已安全/完整”的推断。没有语义分组、语言判断、隐私语义检测或上传许可。

当前检查器由合成测试提供；真实接入时必须来自已存在的“点击翻译”任务所有者。本层不能自行验证用户点击或系统权限，也不会自行启动采集。返回后的过期、菜单/收起清理仍由调用方控制，不能把本轮取消回调测试当作完整产品生命周期验收。

## 取舍与上限

| 情况 | 本轮行为 |
| --- | --- |
| 密码/敏感/可编辑节点及被这些节点包含的后代 | 不调用文字读取器，保留不含文字的原因 |
| 自有悬浮层、键盘、系统及其他 App | 不作为目标页上下文；不尝试读隐藏窗口 |
| 可见标记为真，但位置超出屏幕、只露出部分、被遮挡或截断 | 不读取完整标签，避免取得用户当前看不到的部分 |
| text 与 contentDescription 相同 | 保留一次，并记录双来源 |
| 两个标签不同、空白、超长、非法控制字符或破损代理对 | 标记缺口，不猜含义、不拼接、不截掉一部分后使用 |
| 原文空格、换行、法语重音、简繁中文及有效补充字符 | 原样保留，不作文字纠错 |
| 读取器/检查器异常 | 不包含异常消息，分别记录通用缺口或取消整批 |

上限：16 个窗口、512 个节点、每个标签 2000 UTF-16 单元、结果 16000 单元、最大有效期 60 秒；页面边长不超过 10000 合成单位。图结构循环、重复 ID/顺序、缺失父节点、跨窗口父子及无效矩形在任何文字读取前整体拒绝。达到总字符上限后停止继续读文字；单条超出剩余额度则标记缺口，不静默截断。拒绝原因、默认 `toString()` 不含正文。

这些上限约束本层接受的输入和输出，不代表测得了真实树遍历内存/耗时。未来 Android 读取器仍要在 `CharSequence.toString()` 前检查长度，并控制节点获取、遍历、取消和资源释放。Kotlin/Java 字符串不可原地清零；丢弃引用不等于已经擦除堆内存。

## Android 官方证据及尚未解决的映射

- `isPassword()` 是节点密码标记，不能代表所有个人资料都已过滤。`isVisibleToUser()` 也不能单独证明文字完整落在当前显示范围内，官方注明了它在系统放大状态下的局限。[AccessibilityNodeInfo](https://developer.android.com/reference/android/view/accessibility/AccessibilityNodeInfo)
- `isAccessibilityDataSensitive()` 从 API 34 才有；目标华为 API 31 必须记为接口不可用。即使该属性为假，也不能因此宣称没有敏感信息。[敏感数据接口](https://developer.android.com/reference/android/view/accessibility/AccessibilityNodeInfo#isAccessibilityDataSensitive())
- `AccessibilityWindowInfo.getRegionInScreen()` 从 API 30 提供的是可触摸区域，不能当作未遮挡内容的证明；自有无障碍悬浮窗有独立类型。[窗口接口](https://developer.android.com/reference/android/view/accessibility/AccessibilityWindowInfo)

当前 `protectedContent`、`sensitive`、`occluded` 和 `labelScope` 都是**合成样例明确提供的分类证据**。没有将窗口 API 虚构为拥有 `isSecure()`，也没有为真实窗口实现通用的保护状态检测。若将 API 31 不支持的敏感标记直接送入当前保守规则，节点会被排除；这是一项尚待解决的兼容性/可用性缺口，不能通过填默认 `NO` 来“修复”。

树中去掉看懂自己的节点不会还原镜面背后的像素；新用例明确验证目标节点仍标为被遮挡。本轮没有短暂隐藏真实悬浮窗、获取投屏帧或绕过任何安全窗口。

## 已完成验证

- 初始空结果实现上 23 项测试中 20 项失败，证实需要的保留/分类/取消行为尚未实现；实现后 23 项通过。随后审查补充自有悬浮窗遮挡和有效字符保真，最终 25 项新增测试。
- JVM 总计 **190 项**（modelprobe 116、ocrlab 74）通过，无失败/错误/跳过。独立实验主包和测试包构建通过；Lint **0 错误、26 条既有警告**。
- 专用 `KanDong_OCR_API37_16K` 模拟器：最终 **26 项**通过，包含同一组 25 项采集规则及 1 项既有五页展示绑定回归。最终安装包与构建产物 SHA-256 一致。首轮 24 项结果另存，不混算最终测试数。
- 产物权限核对：实验主包没有网络、无障碍或屏幕共享入口/权限；本轮没有读取真实屏幕、开发密钥或调用 DeepL，也没有更新目标华为。正式 `app/compat/graphics` 及冻结翻译资源未改。

证据：[本轮目录](evidence/local-capture-privacy/2026-09-24/summary.json)，包含红/绿记录、完整回归 XML、构建/Lint、两轮模拟器输出与最终源码/安装包指纹。

复现使用仓库现有测试工具，无新增依赖：

```sh
./gradlew --offline :modelprobe:testDebugUnitTest :ocrlab:testDebugUnitTest \
  :ocrlab:assembleDebug :ocrlab:assembleDebugAndroidTest :ocrlab:lintDebug
```

Android 定向类为 `com.kandong.ocrlab.context.capture.LocalCapturePrivacyTest`；只在已核对的项目专用模拟器安装实验主/测试包运行。它不会弹授权、访问第三方 App 或读取当前屏幕。已有点击/菜单/收起/过期展示界面证据见 [展示实验](TRANSLATION_DISPLAY_LAB.md)，这轮只重跑相关绑定回归，不冒称重跑全部 UI 场景。

## 接下来的有界任务

下一项验证真实 Android 节点 API 到本契约的映射，先用应用自有的合成单语页面，而不是直接接第三方屏幕或云服务：

1. 自有页面上对照真实节点的属性、位置和延迟标签读取，区分属性可得、不可用、无法确认，不补造遮挡/安全信息。
2. 验证自有普通页/密码输入/容器汇总、滚动边界、悬浮层遮挡和页面更新；保留 EN、FR、简中、繁中各自独立的页面。
3. 对 API 31 明确制定证据来源与无法读取时的提示；未解决的问题留作缺口，再评估目标华为和第三方 App 的本地采集。获得可追溯节点不等于模型安全上下文，后续仍需语义归属、隐私分类、树/OCR对齐及翻译质量验收。

产品接入、真实内容上传、后端凭据和完整翻译质量仍各自未完成。本轮不扩大 Phase 0A 的屏幕共享授权。
