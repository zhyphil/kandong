# 块级语言候选：运行前固定的实验计划

2026-09-24，承接主动点击翻译与上下文契约。先以随包合成文字评估本机语言证据，不接正式应用、不读取真实屏幕。

候选为 `com.google.mlkit:language-id:17.0.6` 的随包实现，仅加入 modelprobe 的 androidTest。官方接口返回文字串的语言候选及置信值；不能直接给单串内不同语言分段。未判定返回 und，不能把模型名或字形直接当语言。随包模式与动态 GMS 下载模式分开，优先前者；本轮模拟器结果不代表华为可用。[官方接入](https://developers.google.com/ml-kit/language/identification/android)、[语言范围](https://developers.google.com/ml-kit/language/identification/langid-support)。

SDK依照其适用条款使用，不将文档示例Apache许可当模型许可。模型输入/输出的本机处理与SDK可能收集运行指标分开描述。本次测试包显式移除网络权限，核对合并Manifest；实验只传自编合成字符串。[条款与隐私](https://developers.google.com/ml-kit/terms)。

输入冻结于 `docs/fixtures/language-routing-v1.json`：38条，英语6、法语6、中文6（简繁各3）、短词8、纯数字/标点4、混排4、其他语言4。预期标签仅在模型返回后用于评分，不传给模型或选择规则。所有候选/分数和失败均保留。

运行前固定规则 v1：原文不改写；无字母文字保留原样；同时含汉字与Latin字母时待核对（只作为混合字形警示，不推定语言）；少于8个Unicode字母待核对；其余使用全语言候选列表，不先仅筛EN/FR/ZH。最高分至少0.90且领先第二名至少0.20、语言为en/fr/zh时才允许路由：EN/FR进入候选翻译，ZH保留原文；其余待核对。候选列表收集门槛固定0.01。OCR冲突必须在此之前阻断。

该阈值是待验证实验选择，不是校准后准确率保证。尤其同一Latin字形的英法混排不能靠字形规则发现；若模型单语言高分误接收，应明确记录失败，不靠本轮答案补特例。分列识别正确、拒判和错误自动路由，不能用全部拒绝获得好看的安全成绩。

验收顺序：检查固定依赖及包权限/模型身份；JVM验证路由边界与原文保留；模拟器两轮真实模型推理核对重复性和逐项质量。技术运行成功不等于三语路由质量通过。正式翻译、自动语义分组和长辈UI接入仍待后续验收。
