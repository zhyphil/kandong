# 整屏本机 OCR 独立实验

2026-09-25：固定单语整屏经实际 Android Image、检测、裁剪、识别和位置回映，已在专用模拟器及目标华为完成技术验证。**文字质量尚未通过**，尚未接正式放大镜、真实页面或翻译。前一阶段见 [整屏输入](FULL_PAGE_OCR_INPUT.md)。

## 实现范围

新增代码仅位于 `modelprobe` 的测试源集。`FullPageOcrPipeline` 接收整页固定版本的 Image lease，顺序处理全部全宽条带，没有红框/ROI 参数。检测结果已经回映到条带源图，整页坐标只加条带原点，不能再次缩放。

每个模型组最多同时保持一个检测器和一个识别器，单工作线程逐段、逐框执行；所有页面共用该组会话，关闭后才进入另一组。原有三框契约不修改，仅在单框数值缩放时临时使用 box-0；真实轮廓/框索引、阅读次序、来源版本、局部/整页四边形和模型身份全部保留。空串、重叠重复和残片不删除。

边界：每段最多64框、每页128框、原始文字8192 UTF-16单位；识别batch=1、高48、宽320～1024。固定模型输出长度是 `floor((W+3)/8)`，例如452→56，不能用ceil(W/8)。26条既有冻结识别形状由宿主独立核对。超过预算整页拒绝，不返回部分内容。

检查点位于原生调用之间及像素交接期间。取消/版本变化/过期/异常会清理拥有的数组和直接输入、关闭Image，并丢弃整页候选；不能中断正在执行的同步原生调用。Mat释放、Image及会话计数闭合不证明安全擦除全部原生内存，也不构成RSS峰值或长时间稳定性验收。这是新的双会话实验，不套用此前单会话内存结论。

## 冻结输入与判定

推理前冻结 `full-page-ocr-v1/manifest.json`，SHA-256为 `e95fa1bac48e0a32272a65cf4b85679705597b2bbe3ca69997f038fdf26345f1`。仅复用既有单语holdout的8张原PNG；文件哈希、解码RGBA哈希和实际字形边界独立核实，没有新字体渲染或预置模型输出。

10页：EN、FR、Hans、Hant各两种布局，另有1080宽英文接缝页及空白页；其余1176×2400，与目标华为尺寸一致。共19处刻意穿过实际字形的核心/读取边界，非空页首段有超过3行。每组模型处理相同10页，不按参考答案选择模型。

注意：`normal` 是冻结布局名称，**不表示无接缝**。中部块的部分字行也跨read边界，例如Hans/Hant第二行覆盖1119..1143、跨过1136。因此normal产生的残片不能直接归因为普通识别错误。冻结布局保持不变，不根据推理结果调整题目。

原PNG被逐行复制到自有ImageWriter，ImageReader取得同一图像交给流水线；没有创建整屏Bitmap或调用MediaProjection。预期文字与位置仅在推理完成后评分。评分使用原始字符串完全相等＋字形包围框相交，只是粗位置诊断，不是紧贴字形的多边形精度验收。单纯相交不证明所有框位置准确。

## OCR质量结果

没有做去重或纠错时，20个模型/页面组合只有5个严格全页精确：两模型的英文normal、Latin的法语normal、两个空白页。它们是固定布局诊断，不是产品通过率。对应目标语言的详细计数如下；另一模型的全部错误同样保留在原始报告中。

| 页面 | 观察的模型 | 预期行/实际候选 | 无完全正确候选的行 | 多余正确重复 | 其他错误/残片候选 |
|---|---|---:|---:|---:|---:|
| EN normal | Latin | 8/8 | 0 | 0 | 0 |
| EN seam | Latin | 12/16 | 0 | 3 | 1 |
| EN seam 1080 | Latin | 10/14 | 0 | 3 | 1 |
| FR normal | Latin | 10/10 | 0 | 0 | 0 |
| FR seam | Latin | 15/20 | 0 | 4 | 1 |
| Hans normal | ch | 8/9 | 0 | 0 | 1 |
| Hans seam | ch | 12/16 | 0 | 3 | 1 |
| Hant normal | ch | 8/9 | 0 | 0 | 1 |
| Hant seam | ch | 12/16 | 1 | 2 | 3 |

例如ch法语会把à变为a；Hant页可把「稅」写成「税」。完整正确候选与接缝误识别可能同时存在，不能选择符合参考答案的那个输出冒充运行规则。本轮未做语言自动路由或翻译验收。

## 下一项已执行的核心归属基线检查

在冻结实际输出上，仅保留 `ownsCoreCenter=true`，不使用预期文字决定去留。该规则减少英法/简体页的重复，但Hant seam丢掉了p2/1原来存在的正确候选：原始输出1行缺少完全正确候选，过滤后增为2行。**拒绝把核心中心归属直接作为去重规则。** [全部20组结果](evidence/full-page-ocr/2026-09-25/core-owner-screening.json)。

下一步先做跨段空间关联，保留参与关联的所有原始ID、文字、位置及冲突原因；重叠同文可以作为同一元素的证据，冲突或裁断须待核对，不能丢掉另一段候选或凭期望答案纠错。还需要独立反例覆盖相邻列、相同文字出现在不同位置、核心边界漂移、超出halo的长高字行和部分裁断；验证完成后才接整屏上下文与区域显示。
