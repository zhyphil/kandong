# 固定整页 OCR 与翻译绑定演示

本阶段接续 [OCR 翻译契约](OCR_TRANSLATION_BINDING.md)，只改独立“看懂选区实验”。正式放大镜、手机安装、联网供应商和真实页面采集不在本轮范围。

## 操作与证据边界

- “整页 OCR”保留原来的原图／候选检查路径。
- “翻译演示”先创建点击票据，再重新获取随包固定页并执行一次实际整页 OCR。英语／法语的异步返回是本机生成的绑定标记，明确不是译文；简体／繁体中文保留原文，不请求演示回复。
- 整页上下文完整保留，红框仅选择卡片。原图镜面编号和卡片依据同一原始候选对应；重复、冲突和空串不消失，不推断语义组或选择正确答案。
- 移框、倍率、镜面平移及“原文对照／演示结果”只更新展示，不重新识别或提交请求。“原文对照”是本实验的比较视图，不是产品里的“结束翻译、返回原图”操作；产品结束翻译仍须丢弃文字和在途结果。
- 取消、换页、菜单、收起、后台及销毁撤下结果；恢复不会自动识别。有效期以原图取得时间为准，不能因回复、切换视图或移动选区而续期。过期后需要再次主动点击。

固定素材来自项目内已认证 PNG，页面语言按素材声明。实际 OCR 和资源清理通过不等于识别质量通过；结构与位置对应通过不等于供应商使用了上下文或译文准确。界面上的绑定标记不能作为翻译示范给长辈使用。

## 实现范围

仅 `modelprobe` 测试源集的界面、异步后端、纯展示协调器和验证文件。复用原 `FullPageVisualOcrRunner`、`RegionOcrBridge` 和 `FullPageTranslationProbe`；保留工作线程交付的原收据及校验时间，不重复推理。取消不提前释放原生执行槽位，等待实际资源清理结束后才能再次启动。

异步演示调度器不持有 Activity；取消移除回调并释放请求引用。过期／外来回调先检查对象身份，再读取时钟或改变当前显示。实验不新增网络、屏幕共享或无障碍权限。

## 复跑

使用本项目专用 `KanDong_OCR_API37_16K`，端口 5582；配对安装主／测试 APK 后打开 `com.kandong.modelprobe/.RegionVisualLabActivity`。点击“翻译演示”；使用“换页”依次看 EN／FR／Hans／Hant，红框决定显示内容。正式产品入口不受影响。

证据目录 `run-checks.py` 提供 `build`、`install`、`tests --classes RegionVisualTranslationUiTest`；每次使用新的输出目录。脚本固定核对 AVD／API37／ARM64／16KiB 和两包 SHA。`check-standalone.py` 接受新输出目录及 `--build` 指向本次构建结果，验证独立启动。检查前先启动专用模拟器，不使用其他项目 AVD。
