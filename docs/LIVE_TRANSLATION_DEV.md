## 实际流程

`compat` 的 debug 构建安装为 **看懂开发版**（`com.kandong.compat.dev`），保留已验收的红框拖动/独立宽高、1–5倍滑杆、镜面平移/双指缩放、自动上下避让、收起/恢复、全屏菜单和停止逻辑。release 仍无 OCR、网络权限或本次新增模型依赖。

1. 用户照常手动允许悬浮窗和本次屏幕共享。共享本身不授权 OCR/联网。
2. 点镜面“翻译”，界面只有英语/法语、简短说明和“开始翻译”；隐私详情可展开。开始按钮旁明确本次整屏可读文字（含红框外）会发给 DeepL、仅公开页面、图片不上传和供应商可能留存。点击就是本页识字与联网的明确指令，不加勾选框；关闭或只切换语言不会采集/联网。
3. 按开始后暂时移除自身窗口，经随机九格标记、新生产者时间戳、无遮挡且非全黑的可见区域验证，取得一张整屏 RGBA。仍在4.5秒限时内跳过全黑帧，失败恢复原文。镜面固定显示“本次快照”，本机 ONNX/OpenCV 识别整页；红框不裁掉上下文。没有 Accessibility Tree 权限扩展。
4. 本机OCR成功后，在同一工作线程直接请求 DeepL；不展示识别文字预览、不第二次确认。整屏所有安全区域内可读块逐块发送，并将全页文字作为 context，返回按ID/顺序绑定。切边或无法识别的块保留原图/橙框、显示跳过数量，不猜补；空白页不发请求。敏感信息过滤、取消/处理超时、配额和故障守卫仍有效，不自动重试。首版入口不再提供简繁中文或本机识字路线；底层库/历史实验的本地识别能力保留。
5. 译文直接出现在同一快照的镜面，按来源位置裁剪、省略；点“全文”看选区涉及块的完整原文/译文，返回保留选区、倍率和偏移。取图后底层滚动不取消或重取，移框只复用本次结果；已完成结果不自动过期，新的翻译成功才替换；失败、取消或空页保留上一份。点镜面左上角“实时”主动清除并切回当前画面；收起/菜单保留完成结果、取消未完成处理，停止/锁屏/旋转/撤销共享清理。没有预置译文，全文不再次OCR/联网。

新入口与Mac relay使用deepl-free-direct-v2披露版本；旧的预览确认契约会被拒绝，更新后需同步重启relay并配置新临时令牌。

按按钮与取得无遮挡画面之间存在短暂的隐藏/采集间隔；取图完成前仍需保持目标页面。不能声称抓取到了物理按下瞬间的帧。

公共英/法/中文试用页由 Android 当前渲染，仅提供公开原文，走同一实时采集/OCR路径；它不是第三方 App 兼容性证据。

## 历史 USB 开发连接（90ffe4b及以前）

DeepL 密钥只由 Mac 端项目私有配置加载。开发版只连接经 USB 转发的 `127.0.0.1:18741`；明文例外仅该回环地址，其他地址拒绝明文。Mac 监听127.0.0.1，不监听局域网。临时随机令牌与供应商密钥分开，4小时后失效；令牌以私有权限配置到本应用沙箱，绝不写入 APK/Git 或终端输出。

```sh
python3 -B scripts/translation_dev_relay.py
# 在另一终端，确认 nova 9 上开发版已安装后：
python3 -B scripts/provision_translation_relay.py
```

启动 relay 不调用 DeepL。只有用户在新入口点击“开始翻译”的请求才查询免费额度/请求翻译；只接受现有 API Free `:fx` 密钥，固定官方 HTTPS 地址，不切换付费端点。每页最多50块/6000字符、JSON 32KiB，单次启动最多100请求/20000字符；无重试、重定向、图片上传、页面日志或落盘。配额查询与消耗之间仍可能存在其他客户端并发，服务商额度错误按失败处理。

终止 relay：其终端按 Ctrl-C，并运行 `adb -s 2AS0221B09001601 reverse --remove tcp:18741`。正常退出删除 Mac 临时令牌；应用私有令牌随后因进程随机令牌/时限失效。此段仅记录旧版连接；新云端路线见文首，尚待部署和拔线验收。

## 内容与状态边界

DeepL 官方说明：数组各项独立翻译，共享上下文需显式传入 `context`；提供上下文不等于已证明语义准确。[请求文档](https://developers.deepl.com/api-reference/translate/request-translation)。本次核对的[隐私政策](https://www.deepl.com/en/privacy)第13节将 API Free 关联至第3节免费服务条款，因此界面保守披露临时留存/改进用途，不承诺零留存，不允许个人/保密页面。

简单敏感词、邮箱、长卡号等在手机和 relay 各拦一次；这不是完整敏感内容识别。入口明确只用于公开页面；取消预览后，不再要求查看OCR全文，识别错误和漏检仍可能存在。已发送给供应商的请求不能通过关闭界面撤回。

页版本与选区/倍率分开：移框复用一次有效 OCR/翻译；缩放和平移只改变显示。60秒仅限制从取得原帧起的本次识字与联网处理，不能通过重绘/联网刷新；成功结果没有阅读时限。新结果未成功前，仍显示上一份完整快照，不将旧文字叠在新图片上。收起/菜单只取消未完成请求、保留已完成结果；“实时”、停止/锁屏/旋转/撤销共享丢弃全部快照和文本引用，拒绝迟到结果；恢复不自动读取/翻译。一次同步原生推理无法硬中断，但每次原生调用前后检查取消，清理后不发布。

最多保留上一份已完成快照与一份处理中的候选快照，只在内存保留，主动退出或结束会话时释放，不写相册或磁盘；供OCR使用的完整 RGBA 在处理结束/失败时清零。Java/Kotlin/Python字符串无法承诺安全擦除，依靠去引用和不落盘。运行诊断仅计数、状态码与几何，不包含文字、图片、令牌或供应商响应。


分段规则：整屏的每个主要区域均处理完成后才发布结果。重叠区中由人工分段产生的残缺副本不再否决整页，也不要求与某一整行几何完全一致；仍保留原始候选总数。按用户最新要求，主要区域内的切边文字也只跳过该块；单块裁剪几何或识别尺寸预检不通过时同样保留原图，其他可读块继续。真正的原生/模型运行失败或取消仍停止。屏幕边缘未显示的字符不推测补全，实际漏字/错字仍需对照原图；这不是完整性保证。

## 失败后的恢复

发送阶段区分USB/Mac连接不可用、等待超时、临时连接失效及翻译服务异常；快照剩余时间不足、源语言不符、单次连接上限和DeepL免费额度也分别说明。工具栏保留简短原因，临时提示提供恢复动作；原始异常/服务端正文不显示。出错仍清除本次快照和文字、恢复实时放大，不自动重试或重新上传。修复连接后须重新点翻译，在入口重新确认本页识字及自动翻译。此轮84开发版+10relay检查、构建/Lint通过且已装真机；实际拔线/弱网场景尚未验证。
