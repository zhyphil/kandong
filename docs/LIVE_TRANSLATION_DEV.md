# 真实页面翻译开发版

2026-10-01，基于 `2584bad`。目标是先交付能在 nova 9 上直接试用的真实流程，不再将独立语料规则实验作为接线前提。此文中的“开发版已实现”不等于真机体验或翻译质量验收。

## 实际流程

`compat` 的 debug 构建安装为 **看懂开发版**（`com.kandong.compat.dev`），保留已验收的红框拖动/独立宽高、1–5倍滑杆、镜面平移/双指缩放、自动上下避让、收起/恢复、全屏菜单和停止逻辑。release 仍无 OCR、网络权限或本次新增模型依赖。

1. 用户照常手动允许悬浮窗和本次屏幕共享。共享本身不授权 OCR。
2. 点镜面“翻译”，选择 EN / FR / 简体中文 / 繁体中文和处理方式，另行勾选本次整页本机识字。
3. 暂时移除自己的全部窗口，显示随机九格采集标记。先观察到标记，再观察到生产者时间戳更大、标记全部消失且可见区域采样非全黑的帧，才复制一份当前整屏 RGBA。全黑帧继续等待（仍在4.5秒限时内），超时明确显示黑屏取图失败，不运行OCR。4.5秒失败则恢复原文；不把固定延时当成新帧证明，也不跨时钟比较。
4. 原窗口立即恢复，镜面固定显示“本次快照”，不再跟随底层实时页面。`liveocr` 在单个后台线程调用已固定的本机 ONNX / OpenCV 检测、裁剪、识别，保留整屏块的位置和身份；红框不参与输入裁剪。系统栏外的完整识别块作为当前页文本。本次不接入 Accessibility Tree 服务，不扩大原放大镜无障碍权限。
5. 本机默认仅显示识别原文；若某些候选块没有读出文字，其位置保留快照原图、加橙框，并显示“X处未读清”。其他已识别文字正常显示，不猜补缺字。尚无验收通过的英法离线翻译模型。中文不转换简繁、不请求 DeepL。
6. 选择 DeepL 后，先显示本页将发送的**全部**文字。用户检查公开/非敏感内容，逐页确认后才发送。正文数组逐块绑定，另把整页文字作为 `context`，不能只发送红框内容。DeepL 响应按同一请求的顺序/ID绑定。有未读清处时，预览另行说明这些位置没有文字可发送、上下文可能不完整；确认文字要求用户核对未读清处，也可点“先查看识字结果，不发送”回到同一张快照。不会把空块/图片发送给服务商。
7. 按用户最新要求，一次点击只取一张快照。后续OCR、联网全文预览、发送与结果均绑定这张快照，底层滚动或切页不再取消，也不再次采集核对。镜面按快照中源块位置显示文字，标注“本次快照 / 机译待核对”。点“原文”退出后恢复实时放大。没有预置译文或录制回放。

按按钮与取得无遮挡画面之间存在短暂的隐藏/采集间隔；取图完成前仍需保持目标页面。不能声称抓取到了物理按下瞬间的帧。

公共英/法/中文试用页由 Android 当前渲染，仅提供公开原文，走同一实时采集/OCR路径；它不是第三方 App 兼容性证据。

## USB 开发连接

DeepL 密钥只由 Mac 端项目私有配置加载。开发版只连接经 USB 转发的 `127.0.0.1:18741`；明文例外仅该回环地址，其他地址拒绝明文。Mac 监听127.0.0.1，不监听局域网。临时随机令牌与供应商密钥分开，4小时后失效；令牌以私有权限配置到本应用沙箱，绝不写入 APK/Git 或终端输出。

```sh
python3 -B scripts/translation_dev_relay.py
# 在另一终端，确认 nova 9 上开发版已安装后：
python3 -B scripts/provision_translation_relay.py
```

启动 relay 不调用 DeepL。只有手机逐页确认的请求才查询免费额度/请求翻译；只接受现有 API Free `:fx` 密钥，固定官方 HTTPS 地址，不切换付费端点。每页最多50块/6000字符、JSON 32KiB，单次启动最多100请求/20000字符；无重试、重定向、图片上传、页面日志或落盘。配额查询与消耗之间仍可能存在其他客户端并发，服务商额度错误按失败处理。

终止 relay：其终端按 Ctrl-C，并运行 `adb -s 2AS0221B09001601 reverse --remove tcp:18741`。正常退出删除 Mac 临时令牌；应用私有令牌随后因进程随机令牌/时限失效。真正独立手机联网和商业服务端仍未实现。

## 内容与状态边界

DeepL 官方说明：数组各项独立翻译，共享上下文需显式传入 `context`；提供上下文不等于已证明语义准确。[请求文档](https://developers.deepl.com/api-reference/translate/request-translation)。本次核对的[隐私政策](https://www.deepl.com/en/privacy)第13节将 API Free 关联至第3节免费服务条款，因此界面保守披露临时留存/改进用途，不承诺零留存，不允许个人/保密页面。

简单敏感词、邮箱、长卡号等在手机和 relay 各拦一次；这不是完整敏感内容识别。用户仍须查看整页识别内容。已发送给供应商的请求不能通过关闭界面撤回。

页版本与选区/倍率分开：移框复用一次有效 OCR/翻译；缩放和平移只改变显示。60秒从取得原帧起计，不能因进入确认页或联网而刷新。收起、菜单、原文、停止/锁屏/旋转丢弃快照、文本引用和迟到结果；恢复不自动读取/翻译。一次同步原生推理无法硬中断，但每次原生调用前后检查取消，清理后不发布。

快照仅在内存保留，退出/过期时释放，不写相册或磁盘；供OCR使用的完整 RGBA 在处理结束/失败时清零。Java/Kotlin/Python字符串无法承诺安全擦除，依靠去引用和不落盘。运行诊断仅计数、状态码与几何，不包含文字、图片、令牌或供应商响应。


分段规则：整屏的每个主要区域均处理完成后才发布结果。重叠区中由人工分段产生的残缺副本不再否决整页，也不要求与某一整行几何完全一致；仍保留原始候选总数。主要区域的文字被内部读边界切断、识别流程失败或取消时仍停止。屏幕边缘未显示的字符不推测补全，实际漏字/错字仍需对照原图；这不是完整性保证。

## 已知限制和待验收

- 首版需要 Mac/USB；本机英法路线目前是识字，不冒称离线翻译。
- 任意页面的实时新帧标记、第三方 App、受保护窗口和 nova 9 新手势尚须实际验证。原 LIO-AN00/模拟器证据不能替代这次新机。
- 用户已改为快照模式，不做持续页面变化监控。后续原App变化不会更新本次快照；需退出后重新点击识别。只读当前可见页，不读取屏外历史或绕过受保护窗口。
- OCR最多128候选/8192字，4,194,304像素，分条读取。真正归属本段的文字被内部读边界裁断仍拒绝；非归属重叠片段不再否决整页。空识别位置单独保留原图并披露，全部无可读文字时仍提示未读到文字。不能由技术流程推断识字完整或质量通过。
- 字块排序为上到下/左到右，不等于语义分组已正确；行断裂、金额/单位、否定条件、法语重音等仍须对照。图像识别或翻译可能有错。
- 镜面按源块绘制文字，长译文的换行、重叠、裁切和长辈可读性未验收；可点“原文”立即退出。这是开发显示，不是完成的网页重排或像素替换。
- 暂不宣称语言自动识别、混排、多OEM、耗电、订阅或上线发布完成。
