# 看懂 UI / UX：随用随开的放大镜

当前范围是华为兼容版的日常使用体验。保留自由宽高取景、独立1～5倍滑杆（新会话2倍）、镜面滑动和自动上下避让。翻译、账户与订阅暂不接入服务。

## 四个主要界面

| 界面 | 目的 | 主要操作 |
| --- | --- | --- |
| 首页 | 清楚地开始一次使用，了解必要权限 | 一个主要开始/继续按钮、本次共享同意、菜单 |
| 展开放大镜 | 看清当前选中的内容 | 图标菜单、收起、结束；宽幅倍率滑杆；镜面单指滑动、双指缩放 |
| 贴边悬浮按钮 | 给原App让出操作空间 | 点击恢复；拖动换位置，松手吸附左右；长按打开菜单 |
| 全屏菜单 | 集中查看帮助、隐私及后续设置 | 顶部返回/关闭，正文滚动，主菜单底部关闭放大镜 |

收起后，镜面、取景框和右上角角柄全部退出屏幕，只留一个完整可点的放大镜按钮。按钮不藏一半到屏外。拖动不等同于点击，拖走再拖回、取消或多指都不能误触展开。

展开/收起/菜单之间保留当前选区、倍率、镜面内滚动位置。彻底结束后重新开始才恢复默认2倍并重新请求本次系统共享授权。自动上下避让仍只改变显示窗，不改变原App或选区。

## 图标与信息层级

暖白首页、深青主色、深色正文和克制的辅助色，使用统一圆角与间距。图标用本地线条矢量表达，不依赖emoji字形。图标视觉约24～28dp，所有主要操作至少48dp点击区域，贴边按钮约56dp。图标提供中文读屏标签、按压反馈和长按说明。收起使用常见横线，关闭使用叉号，并各配小字“收起/关闭”，帮助区分暂放与结束；悬浮按钮只显示纯放大镜，不加加号。

首页保留清楚的文字主按钮；菜单条目也使用短标签，避免要求长辈猜测全部图标。红框内部/边框直接拖动，不再要求找移动图标；右上角用24dp圆形角标配16dp箭头，透明触摸区仍为48dp。收起/关闭使用图标加短标签。内容可随系统字号变化并在必要时滚动，避开系统栏和刘海。

## 直接操作

- 拖红框内部或边框移动选区；拖右上角调整宽高，固定左下角。箭头不会因显示窗换边而换到其他角。
- 镜面双指捏合/张开缩放，范围1～5倍；数字、实际矩阵与滑杆同步。以两指焦点为缩放中心，边界处约束平移。单指继续用于查看超出的图像，抬起一根手指后重新定位触点，避免跳动。
- 红框接收自己的拖动操作，不向底层转发点击。需要操作原App时收起，恢复后保留选区/倍率/镜面偏移。
- 小角标优先绘制在选区右上角外侧；触摸范围可与选区相交。靠近屏幕右上角时角标会被约束到屏内，可能出现在放大画面的角落，不能伪造底下被遮住的文字。待真机实看评估该局部遮挡。

## 菜单内容

主菜单和帮助/隐私二级页都铺满屏幕，背景不保留浮窗的圆角和四周留白。系统栏/刘海区域保留安全间距，顶部导航与底部操作均可见。首页入口和放大过程中的入口一致；全屏菜单空白处也不将触摸传给原App。关闭后移除整页并恢复原先展开/收起状态。

- 使用帮助：说明选区、倍率、镜面滑动、收起/恢复和结束。
- 隐私说明：准确解释屏幕读取、暂停及结束。
- 区域翻译设置：标注“准备中”，本版不执行翻译或提供假的开关。
- 账户与订阅：标注“准备中”，本版无需登录，不展示虚构价格、购买或支付流程。
- 会话运行时，只有主菜单底部提供“关闭放大镜”，并注明“同时停止屏幕共享”；它结束本次辅助会话，不主动退出首页或杀进程。
- 帮助/隐私二级页只保留顶部返回箭头、页面标题和关闭菜单图标，正文独立滚动，底部没有重复的关闭菜单/结束按钮。关闭菜单返回进入前的展开或收起状态；左箭头及返回键回到主菜单。

菜单为后续功能保留位置，不代表已实现OCR、翻译服务、账号系统或收费。上述功能需后续独立产品/数据/支付方案和验收。

## 收起与结束的区别

收起及打开菜单时暂停画面处理，清除当前显示图像；保留本次系统共享，以便点一下恢复。系统可能仍显示共享标记。点“关闭放大镜”才释放整个共享过程；锁屏、系统撤销共享、旋转或服务结束也统一清理。

收起不意味着后台继续保存或上传屏幕，也不能在界面声称“共享已结束”。没有网络、页面文字日志、自动点击/输入或额外权限。菜单和悬浮按钮保持受保护窗口，测试时不为了截图解除保护。

## 本轮验收

1. 收起后只剩悬浮按钮，原App恢复正常点击和滚动；应用停止复制/显示画面。
2. 点击恢复保留选区、倍率和镜面偏移，等待新画面；多次操作不重复创建共享。
3. 拖动、左右贴边、轻点与长按行为明确，不因取消或多指误展开。
4. 展开/收起均可进菜单；帮助与隐私可读，规划功能不可操作；退出菜单回到原状态。
5. 结束、锁屏、撤销、旋转后全部辅助窗口消失，不能自行恢复。
6. 原有倍率、自由选区、镜面滑动、自动避让和原App布局/点击回归通过。

实际执行结果与未覆盖项见[VALIDATION](VALIDATION.md)，不能把设计目标当成已通过的设备结果。
