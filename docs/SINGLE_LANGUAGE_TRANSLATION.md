# 当前首版：单语页面的整屏上下文翻译

2026-09-24，用户明确修正：语言测试只需单一英语、单一法语或单一中文；核心是在看到这样的界面时准确翻译，结合全屏上下文整体理解，在放大镜中显示对应内容。本文件是当前执行优先级，替代旧混排语言筛选/校准下一步。历史实验与失败保持原样，范围调整不等于旧候选通过。

## 产品验收

点击“翻译” → 获取当前前台页面全部可见内容 → 保留标题、段落、卡片、按钮、数字、条件和位置关系 → 结合整页理解并翻译 → 镜面显示红框对应内容。

- 首版页面分别为EN、FR、ZH，不做同屏/同块混排验收，也不继续为混排挑选或校准语言模型。数字、货币、时间、标点仍是单语页面的重要组成部分。
- 按已确定方向，英语/法语译为中文；中文保留原文与元素对应，简体/繁体分列。翻译不增加无依据的解释；中文改写/其他输出语言不是本轮新增要求。
- 源语言可结合完整单语页判断；无需对每个“Book”“Vol”或数字按钮单独做语言分类。判断不清楚时提示，不为了达成覆盖率强猜。当前人工语言字段不等于自动判断已实现。
- 模型输入必须有完整可见页面上下文和目标元素/组ID，不能先裁成红框文字、只译孤立短词，或把全页译文按顺序机械切回原框。
- 全页可以参与理解，各卡片的金额、单位与限制仍保持归属；不能将另一张卡片的条件移过来。显示原文与上下文补充可核对，翻译不得夹带推测。
- 同页移动选区复用本次结果；缩放只改变显示。滚动/页面变化/过期撤下旧结果，等待再次点击；收起、菜单、停止取消处理并清空。可见页面不含屏外历史/后台/通知或看懂自有窗口。

## 接下来的顺序

**下一项直接验证真实翻译的上下文效果，不再先解决混排分类。**

1. 用完整单语合成页面独立接入一个真实翻译候选。先核对实际可用构件、上下文输入方式和运行条件；沿用本机优先，不因本轮范围修正扩大为云端上传。先使用正确的原文隔离翻译质量，再接已识别文字判定OCR影响；先让译文链路产生真实结果，不用手工中文宣称完成。
2. 同一页面分别提供完整上下文和仅目标短词，记录实际输入/模型版本/译文与原ID；答案、语义标签和测试case名称不进入模型请求，避免把预期意思泄漏给模型。通过以下单语场景核对语义，不要求中文逐字等于唯一模板。
