# 点击翻译：一次点击处理当前页

2026-09-24 用户补充已成为正式产品约定：镜面工具栏提供“翻译”按钮，点击后才处理当前屏幕的可见文字，相关译文显示在放大镜展示区。此轮完成独立合成实验，没有接入正式放大镜或真实翻译模型。

## 行为

- 打开应用、放大镜、恢复悬浮窗、移框及缩放均不启动文字处理。
- 点击“翻译”取得一次当前页面采集资格；处理期间重复点击不叠加排队。采集资格只能使用一次，过期或旧页回调无效。
- 捕获结果必须来自点击之后，页面/窗口/显示屏/内容版本相符。对本次快照中的可处理目标准备演示请求；选区只决定显示，不限制完整可见上下文。
- 同页移框、缩放只改变展示，复用这次结果。滚动、页面或内容变化以及过期撤下结果，等待再次点击。
- 显示原文、收起、菜单、停止取消本次文字处理；返回不会自动重开。采集和文字结果只留有效会话；迟到结果不能恢复旧内容。

纯 Kotlin `OnDemandTranslation` 复用既有 ContextEngine；不包含屏幕采集器或模型。页面变化信号现在由实验手工提供，真实页面监测、权限和采集一致性另行实现。忙碌/失败/待刷新均有状态，没有给正式产品加入假翻译按钮。

## 验证

共131项JVM测试通过（ocrlab49、modelprobe82），包含8项新触发/失效用例；构建与Lint通过、零错误。新功能未声称有旧实现红灯记录。

专用API37模拟器两轮各8项新状态测试通过；另8项实际界面检查通过：初次进入与移框处理次数0，点击后为1且展示对应中文，移框仍为1，页面变化撤下译文且不重跑，再次点击计数2，显示原文清除中文，退后台返回不恢复。截图已目视核对。实验页使用随包人工英文和中文，无OCR或翻译模型调用。

实验入口：“看懂文字实验”→“点击翻译交互实验”。按钮标注“翻译（人工演示）”，声明始终随页面内容展示；这不是最终产品UI或长辈可用性验收。APK仍无网络权限、无真实屏幕读取权限。
