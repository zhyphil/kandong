# 看懂 v0.1.0 · 核心放大镜

首个固定核心交互的 Android 版本。面向需要看清手机内容的人，在其他 App 上局部放大原画面，保持原页面排版。

## 已固定的核心体验

- 直接拖动红色选框移动选区；右上角小箭头独立调整宽高。
- 放大画面支持双指缩放和倍率滑杆，1～5倍、每次新会话默认2倍；数字和滑杆同步。
- 单指滑动查看超出显示窗的内容；显示窗自动避到选区另一侧。
- 收起成可拖动的贴边放大镜按钮，轻点恢复原选区、倍率和查看位置。
- 全屏菜单、使用帮助和隐私说明；随时关闭放大镜及屏幕共享。

## 安装与使用

下载 `kandong-v0.1.0-android.apk`。最低 Android 10/API29；当前核心交互已在华为 LIO-AN00（Android12/API31）由用户实测，专用 Android16/API36 模拟器完成回归；最低版本和其他机型尚未逐一验收。

首次安装后，按应用提示允许悬浮窗，再由本人确认每次屏幕共享。直接拖红框，双指在放大画面里缩放；要操作原App时先收起。锁屏或旋转后停止，需要重新开始并授权。

**从此前开发调试版迁移：**正式版使用独立发布签名，与0.0.x调试版不能覆盖安装。需要自行卸载旧“看懂”再安装，重新开启悬浮窗权限。以后同一发布签名的正式版本可正常升级。

## 隐私与范围

屏幕共享会提供整屏缓冲区；看懂仅在本机复制选区显示，不录像、不保存、不联网、不上传。收起和菜单暂停处理，但保留本次共享会话；关闭后释放。没有自动点击、输入、购买或支付。

此版本仅发布 `compat` 放大镜。翻译、AI解释、账号和订阅尚未提供；未提交应用商店审核。极端右上屏角的小角标可能局部遮挡内容，大字号/TalkBack及长期使用仍待扩展验证。受保护页面可能为空白，不绕过系统保护。

## 校验

同页附 `SHA256SUMS.txt`、`SIGNATURE.txt` 和 APK元数据。本次发布构建关闭调试属性，41项release单测通过，Lint无错误（8项警告）。实际签名APK在专用API36模拟器完成安装、授权、拖框、双指、收起恢复、全屏菜单和停止检查。详细验证与固定基线见仓库 `docs/VALIDATION.md`、`docs/CORE_BASELINE.md`。
