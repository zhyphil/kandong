# v0.1.1 发布说明草稿

状态：未发布，版本号/标签/正式资产尚未生成。本草稿不表示已获推送或发布授权。

## 本次变化

- 成功开启新的放大镜会话后，介绍页自动回到后台并显示手机桌面。取消共享、启动失败或重新打开看懂时，不会反复跳转。
- 菜单新增「清晰增强」：在本机改善文字边缘，首次默认关闭，记住用户选择；随时可以关闭。无需联网，也不会保存屏幕内容。
- 增强使用实际镜面大小输出，支持已有的自由选区、1～5倍滑杆与双指缩放、单指平移。收起/打开菜单时暂停处理并释放增强资源，异常时自动回到普通画面。

- 限制等待显示的增强结果，收起时及时释放；复用本机临时缓冲，减少逐帧分配。画质算法与输出含义保持原样。

核心拖框、独立宽高、自动上下避让、悬浮按钮、全屏菜单及停止方式保持已验收行为。

## 验证与限制

当前开发包为0.1.1-clarity-dev/code7。已有85项相关逻辑测试，目标华为与API36模拟器各144组连续视窗/48组整数倍率数值检查；目标手机已确认文字清楚、操作顺畅。启动跳转和收起/恢复/锁屏/旋转等既有设备记录见项目验证文档。

2026-09-24完成目标手机15分钟混合使用观测：60次采样，增强有效端点覆盖约14分14秒，增强/清理错误计数均为0，电池29→31°C，未报告热状态升级。PSS从约61MiB升至80MiB，长期内存趋势仍待验证；独立持续收起检查及本轮主观反馈待完成，见 [持续验证](../SUSTAINED_VALIDATION.md)。该轮全程外部供电，不能作为耗电对照；断电状态下的长期能耗、更多机型/应用及长辈识读仍需独立验证。

清晰增强是有限的边缘改善，不恢复原始画面没有的细节。感到卡顿、过锐或发热时可关闭。原有屏幕共享披露与受保护页面限制不变。
