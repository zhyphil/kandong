输入分三组：旧38字符串、旧44手工分组页面（合为82条已知回归）、新32页（纯句EN/FR/ZH各4，中文简繁各2；混排8；同组短标签6；其他语言4；字面值2）。新文件[language-lingua-v3.json](fixtures/language-lingua-v3.json)的SHA256 `e2319026a3d8370c205e0c516aedfcb5e41d66f87f1c259c2f68b6c2dbddd59d`；运行后标签只用于评分，不传入模型或规则。

主候选C：

1. 金额/标点无字母保留；同组OCR冲突不推断。每页最多32块、单块512字符，总8192；证据必须绑定原文和页面，子串偏移合法、不重叠；未覆盖的字母或多种分段语言返回待核对。
2. 至少8个Unicode字母时，全语言最高分≥0.90且领先≥0.20、为en/fr/zh，并与单一原生分段语言一致，才产生候选决策。EN/FR→翻译意向，ZH→保留原文。无字形语言映射规则。
3. 短/弱目标可参考同一卡片其他已通过第2步的完整块，锚点语言必须唯一，同组拼接也须通过第2步且一致。目标语言原始分数≥0.10，原生分段语言不得与锚点冲突；目标自身强异语证据不可被覆盖。另一卡片和整页最高分不能提供归属。原文始终保留。
4. 同时记录独立整串候选与分段；不把多语言被识别出来当作已实现翻译，区间只用作冲突保护。本轮不重新调当前ML Kit阈值。

前置技术验收：身份/跨组/原文/缺失证据/分段区间/异常值/生命周期保护的宿主单测；包内SBOM/许可与二进制指纹；本机运行时禁止网络（下载准备与推理分开）。资源观察为进程RSS/峰值与单条耗时，不能替代Android实测；单进程超过1GiB或10分钟终止并记录未完成，候选继续门槛为峰值≤256MiB、热调用P95≤250ms（Mac初筛，不是手机指标）。
