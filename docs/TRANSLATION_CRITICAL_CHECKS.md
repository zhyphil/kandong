# 关键事实校验与明确保留原文（独立宿主实验）

本轮已实现有限的关键事实检查，并完成56个目标的两轮真实DeepL合成回归。检查是译文生成后的本机步骤，不负责改写/修补模型答案。检测到风险时，展示契约输出原文、空译文和“这段翻译暂时无法核对，请先看原文。”；没有风险信号的仍为`candidate-unverified`，`semanticVerified=false`，不能冒称一般翻译质量已经验证。正式Android放大镜未接入本模块或联网翻译。

## 实现范围

`translation_critical_checks.py`不含样例ID或预期答案，不读文件/密钥、不联网、不调用模型。原来的字面检查及冻结实验保留不变。

| 检查 | 目前能处理的范围 | 仍有局限 |
| --- | --- | --- |
| 日期 | EN/FR完整月份名的单个日期→中文年月日，比较年/月/日角色；某日、截至、之前/之后、明确含当天 | 多日期、数字歧义日期、复杂有效期语句保留原文；不能解析任意句子 |
| 金额/币种 | 金额与币种成对比较，€↔欧元、£↔英镑；原文只有$时不猜USD；不允许交换两个金额的币种 | 不推断跨块币种设定，不猜千位分隔；符号和代码的复杂组合可能被保守拒绝 |
| 数量/时间 | 时钟小时/分钟、重量/单位、最大/最小、每件、年龄单位、少量计价周期与税费包含关系 | 不是完整量纲/数量关系分析，未覆盖任意单位和跨句关联 |
| 退改条件 | 若干明确否定、出发/续费后不退款、不可换票等表达 | 复杂相对时长与条件未核实；词义和所有否定作用范围不能靠规则保证 |
| 展示 | 风险项保留原元素ID/位置/分组与原文，译文字段为null，有提示；输入对象不被修改 | 仅宿主展示契约，未加入真实镜面或手机页面 |

返回的原因码只用于调试/后续界面选择，不应原样展示给老人。中文页仍直接保留原文，不经过DeepL或此EN/FR候选检查。单语页面全屏context先交给模型；本模块只核对目标原文与该目标译文，不能替代整屏上下文理解。

## 验证过程

- TDD第一组16项：旧字面检查基线14失败，加入关系检查后全部通过；审查再加7项，先7失败后修复。覆盖错日期、上下限反转、币种金额交换、退款反转、无答案时保留原文、身份绑定等。
- v1在完整API调用前冻结于`15e9fd4`。完整运行结束后核对112条请求与冻结计划、源码指纹、完整源对象绑定，以及v1展示结果逐条回放，随后才切v2。
- 离线历史回放发现9个等价措辞误拦；本轮真实结果另发现“不可退票”“发车后”“最长”等3个正确措辞。新增成对正反例：先出现9/3个失败，再修复；“无条件退款”不能误当“无退款”。这是语法等价支持，不按页面ID放行。
- 最终86项宿主测试通过；保留现有HTTPError测试替身的ResourceWarning，没有报告零警告。Android源码没有改动，因此没有重复无关构建、安装或手机测试。
- 可重复离线回放覆盖203个已有首轮目标：DeepL旧JSON37、纯context14、旧本地C48/D48、本轮56。v2不再误拦前四组已判正确译文；仍漏过一般歧义词错误，证明规则不能作为万能语义判定。

## 运行方式

离线回放（输出文件须不存在，不读取密钥、不联网）：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 scripts/replay-translation-critical.py --out /tmp/kandong-critical-replay.json
```

新的本地请求计划（无网络，当前会使用v2；历史v1证据来自提交15e9fd4）：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 scripts/translation_deepl_regression.py --out /tmp/kandong-deepl-regression-plan
```

只有显式增加`--execute-synthetic`才使用用户已配置的专用凭据；目录须全新，且仅允许固定合成语料。不要为了检查文档重跑接口消耗额度。
