# 清晰增强持续运行验证

目标：在已验收的华为 LIO-AN00/API31、兼容版0.1.1-clarity-dev/code7上，观察较长时间使用时的增强输出、资源状态、内存和温度。此步骤不更改放大镜交互，不新增采集权限。

## 已确定的边界

- 手机由用户操作，用户自行恢复共享/开启增强；工具不点击、不截图、不读取页面文字、不改亮度/锁屏/电池/热管理设置。
- 每15秒读取看懂自身Service数值、仅该应用的meminfo，以及系统battery/thermalservice。只将允许的数字/状态写入报告，不保存原始dump、序列号、共享会话ID或其他应用列表。
- 电池温度与外壳手感不同；充电、屏幕亮度、环境温度和底层App都会影响发热。记录“系统报告的温度/热状态”，不据此声称热量由看懂单独产生。
- USB连接时手机可能显示AC供电；任何外部供电都不能拿电量变化作本轮耗电结论。绝不使用battery unplug/set/reset模拟断电，它不等于实际停止充电。
- PSS是按共享页比例计入的进程内存观察值。上升/回落都要结合GC、GPU缓存、选区大小和模式解释；短时峰值本身不是内存泄漏证据。
- 帧计数只能证明本地处理进度，不能当作屏幕刷新率或端到端延迟。静态页面下计数不增长也不自动判为丢帧。
- 每次有效会话只用内部序号区分。缺字段、ADB断开、未运行、热接口不可用保留unknown，不填0或当作正常。

## 可复用采样

Mac需要现有Python3与Android SDK，无新增依赖。只读检查可以在现有debug版上运行，不要求重新安装。正式release APK关闭Service诊断，工具会如实记录unavailable，不能把它当作崩溃。

~~~sh
python3 scripts/soak-check.py --self-test
python3 scripts/soak-check.py --serial <本人指定的测试机> --minutes 15 --out /private/tmp/kandong-soak/new-report.json
~~~

默认检查机型LIO-AN00；其他已授权设备可显式提供 --expect-model。必须使用新的输出路径，防止覆盖已有证据。--minutes 0只采一个快照；--interval范围5到60秒。Ctrl-C保留interrupted报告。检测到有效HAL报告严重或更高热状态时，采样以thermal_attention退出，提示操作人处理；它不会擅自控制手机或关闭用户应用。

报告每次原子更新，包含采样起止、实际观察间隔、采样耗时、模式/资源/错误计数、PSS、电池温度/供电和热状态；session UUID只用于内存中的重启判定，不输出。若两个端点均为收起但计数增加，只标记“间隔内存在活动”，可能是用户在间隔中恢复后再次收起，不能直接命名为暂停违规。严格暂停验收要另取用户明确保持收起期间的密集样本。有效开启观察时长只累计相邻同一会话的EXPANDED且capturing/clarityEnabled均真的间隔，并排除明显采样断档。它仍是稀疏观察推算，不代表间隔内每一刻都已验证。

## 本轮流程

1. 读取连接、版本、共享状态、供电/温度，确认是指定手机。
2. 用户恢复增强后，正常阅读/滑动/调整倍率约15分钟，保持亮屏。工具不替用户保持唤醒，也不阻止锁屏。
3. 核对有无错误回退、会话重启、资源异常，比较前后PSS及温度范围；询问实际卡顿和手感。
4. 收起后补观察资源/计数，结束本轮采样并保存摘要。若用户提前锁屏/结束，共享正常清理与“15分钟完整运行”分别记录。
5. 只有实际跑完且结果符合时标为本机这一轮通过；不推广为所有App/OEM、能耗测试或无限时长稳定性。

## 真正耗电对照：仍需独立完成

本轮外部供电无法验证耗电。后续应在实际拔掉充电线后，保持同一手机、亮度/网络/页面、相近起始电量与温度，分别比较增强关闭和开启的同等使用时长，并交换测试顺序重复。用户记录开始/结束电量和时间；电量百分比太粗或时长太短时只记“分辨率不足”，不换算精确mAh、瓦数或续航提升。整机电量变化仍包含屏幕、底层App和系统，不能全部归给看懂。需要更精细测量时再选择有依据的设备电流/电量计或外部仪器；当前不安装额外监控、不打开无线调试。

## 资料

- Android官方 [dumpsys](https://developer.android.com/tools/dumpsys)：限定应用查询、meminfo与PSS语义，各平台输出可能不同。
- AOSP [HealthInfo](https://android.googlesource.com/platform/hardware/interfaces/+/master/health/aidl/android/hardware/health/HealthInfo.aidl)：原始电池温度单位为0.1°C，报告换算为°C。
- Android官方 [BatteryManager](https://developer.android.com/reference/android/os/BatteryManager)：电池温度、电量、供电等数据边界。
- Android官方 [PowerManager](https://developer.android.com/reference/android/os/PowerManager)：热状态分级；需要结合具体设备支持情况解释。

本轮数值支持“这台手机的这段混合使用中持续产生增强输出、未采到渲染/清理错误或系统热状态升级”。它不证明所有时刻无卡顿，也不证明不存在内存泄漏。PSS有所上升，下一轮应固定选区/倍率、区分增强开关，延长观察，比较重复展开/收起后的趋势，再决定是否需要优化；不凭一次峰值修改产品。

15分钟内的两个收起样本均为capturing=false、surfaceAttached=false、gpuOpen=false、两类Bitmap尺寸0×0。但这两个端点之间计数曾增长，可能包含短暂恢复，不能当作持续暂停证据。**用户保持收起一分钟的密集检查，以及本轮主观卡顿/发热反馈，仍待完成。**
