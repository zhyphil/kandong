# 实际整页 OCR 到按需翻译契约

2026-09-30，起点559dad4。本阶段将固定图片的实际整页识别证据接到既有按需翻译请求和镜面投影契约。代码仍在独立实验中，正式放大镜没有翻译功能；没有调用翻译服务、读取密钥或采集真实页面。

## 本阶段的验收边界

一次明确点击须发生在取得图片和推理之前。交付时沿用原页面版本、原取得时刻和原有效期，不能在识别完成或译文返回时重新计时。同一有效页面内，选区和倍率只控制显示，不重新识别或请求翻译。

整页上下文须保留框外文字，以及所有原始候选、重复、冲突和空白项。空间关联只作为识别证据，不自动升级成段落、价格卡片或其他语义组；不确定项保留原文并阻止生成对应译文。超出契约预算或无法表示的几何须明确失败，不能静默截断。

英语和法语页的测试返回使用明确的绑定占位标记，仅检查元素对应与生命周期。简体、繁体分别验证保留原文；没有调用外部供应商。页面语言来自固定素材声明，不是新增自动语言识别能力。

回复须绑定当前请求、当前页面、供应商标识及完整源元素。错误绑定、重复或漏项整批拒绝，旧回调不能影响新的请求。结构校验不能发现正确ID下语义错误的译文；这仍需要实际翻译和质量验收。

## 验证记录

最终256项modelprobe＋76项ocrlab本机测试通过；离线构建通过，Lint分别0错误／4警告和0错误／30警告。专用API37／ARM64／16KiB模拟器同包81项检查通过，37.382秒，包含四页实际OCR接线、原可视化界面接线、异步取消、空间关联及原翻译契约回归。模拟器不是华为验收，本轮没有操作或更新手机。

新增单模型来源测试先出现3项行为失败，再通过；独立只读审查发现过期后的第一次点击可能被吞掉，新增测试实际复现1项失败后修复。最终测试同时覆盖等待回复和已显示回复两种状态，首个刷新点击直接开始新采集，忙碌时重复点击仍不排队。两个只读阶段的项目指纹均未改变；审查后的修复由根任务复核并实际重跑。

早期构建／2项设备检查、修复前80项设备回归分别保留，不与最终81项混算。证据入口：[汇总及哈希](evidence/ocr-translation-binding/2026-09-30/summary.json)。正式app／compat／graphics、旧modelprobe main源码及依赖未改；实验ocrlab共享契约仅增加独立单模型证据校验分支，原双模型校验保持。

## 实现与调用顺序

`FullPageVisualOcrRunner.prepare`只预留本次身份，不加载图片或模型。接着观察完整六字段版本并调用`FullPageTranslationProbe.click`，再启动原异步桥；原生资源关闭后，只有经桥接器当前所有者检查成功的证据才交给`captured`。原Controller、Guard和许可继续留在工作线程，不由新适配器重新制造。

`FullPageTranslationAdapter`保留原元数据、全部候选及空间关系；`validatedCopy`复用原关联算法做结构复核和不可变复制，避免两份规则逐渐分歧。有效斜向文字保留四角并标不确定；退化／不能表示的几何整页失败。空白页返回EMPTY，不造空文本块；最多128候选、8192总字符、单块2000字符，超限整页拒绝而不是裁掉上下文。

每个原候选单独映射为稳定的64字符十六进制标识，使用带长度的字段编码及SHA-256；原始ID、分数、模型／字典／检测器身份和来源四角均保留在不可变附属证据中。这里的标识不是模型置信度或隐私证明。语义组和语义关联保持为空，覆盖状态明确标为未验证。空串、冲突、截断及不确定项仍在整页上下文内，但不成为翻译目标。

协调器调用原`OnDemandTranslation`一次生成整页所有合格目标的请求，再选择ROI控制显示；中文在本机生成保留原文的结果，不暴露供应商请求。页面变化、菜单、收起对应的暂停、停止、过期或非法时钟清空当前结果与附属证据。旧回调先核对对象身份，不能推进或回拨新请求的时钟。外部调用者已保留的不可变对象无法强制擦除，真实接线仍须取消任务并丢弃引用。

本轮实际设备测试通过代码调用点击契约，并未在界面新增“翻译”按钮。结构测试中的`BINDING_TEST_ONLY`是元素对应标记，不是译文。当前实验界面仍显示实际OCR候选与原图。
