# OCR 双候选与整屏上下文关联

2026-09-24：独立合成实验验收完成。未接正式放大镜、真实屏幕采集或翻译模型，未操作真机。

## 本轮完成

`ContextBlock` 新增 OCR 证据：页面像素身份、两识别器原文、原始四角、选中来源和待核对原因。块 ID 与阅读顺序沿用检测结果；未知文字仍有块和位置，不通过丢掉空串或冲突框伪造完整页面。

契约校验会拒绝跨页证据、缺失或重复模型、虚假的双方一致、被改写的选中文字，以及不对应的几何；保存时冻结嵌套集合，外部改变输入列表不能改写已保存页面。选中来源只记录决策，不代表文字必然正确。

测试桥 `CandidateContext` 调用已验收的 v3 选择规则，再将**所有检测到的块**交给同一份 `ContextEngine`。语言为 `und`，置信度未知；不根据 Latin/汉字分支猜 EN、FR、ZH。纯空白保留为未知块，冲突保留为 CONFLICT，原双候选留在证据字段中，不拼入确定原文。

所有块须有明确提供的人工语义组，未归组或重复归属拒绝整个输入。当前人工分组不是自动理解页面，检测到的全部块也不等于图上所有内容均已识别。几何保留原始四角；选区命中沿用轴对齐外接矩形，未验证真实 Android 屏幕坐标或斜框精确命中。

- 红框只包含价格，但同组框外条件有冲突：目标保留该条件与原因，暂停该组演示译文。
- 另一张明确独立的卡片没有缺失证据：仍能提交独立的合成演示请求。
- 同页移框/缩放：复用同一快照，显示以最新选区为准。
- 换页、过期、收起/菜单/停止或无效替换：清除引擎内上下文和结果，拒绝旧请求回写。

原上下文契约、引擎与几何三个纯 Kotlin 文件移至 `ocrlab/src/contextShared/java`，由 ocrlab 主实验与 modelprobe **测试代码**编译。没有复制第二套引擎，没有引入新依赖。modelprobe 主 APK 不包含这份桥接或上下文代码。

## 运行

使用项目 JDK17，构建两独立模块；主/测试 APK 装到已验证的专用模拟器后执行：

```sh
./gradlew :ocrlab:testDebugUnitTest :ocrlab:assembleDebug :ocrlab:lintDebug \
  :modelprobe:testDebugUnitTest :modelprobe:assembleDebug \
  :modelprobe:assembleDebugAndroidTest :modelprobe:lintDebug --offline
python3 -B scripts/run-candidate-emulator.py --context --targeted \
  --output /private/tmp/kandong-context-new-run
```

脚本限定 `KanDong_OCR_API37_16K` / `emulator-5582` / API37 / 16KiB 和对应 APK 指纹，输出目录须不存在。`--context` 选择本轮构件；不带该参数仍是历史 v3 包。没有将脚本放宽到任意手机或模拟器。
