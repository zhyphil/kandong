# 可选联网翻译：模式、候选与当前进展

2026-09-24用户确认：**支持用户主动选择联网翻译，也保留本地能力**；随后询问免费服务商。此决定解除“必须完全离线”的路线限制，不表示允许静默发送手机页面或自动开通付费服务。默认本地、联网显式选择；本地模型质量仍未通过，不包装成已可用功能。

## 用户体验约定

菜单的“翻译方式”未来提供本地/联网两种选择。选择联网时明确显示服务商、发送的是**当前整屏经过过滤的可见文字与元素关系**（包括红框外的上下文）、数据用途和留存说明；本次会话明确同意后，每次点击“翻译”才采集/发送当前页。原文放大不触发翻译。

- 本地失败不自动上云；联网失败不切换其他服务商、不自动重试、不自动扣费升级。提示后由用户重新点击或切换方式。
- 选择服务商、模型版本或披露版本变化：清空旧文字/结果，撤销旧同意，等待新的选择与点击。
- 同页移动选区和倍率变化不重新翻译；翻页/窗口变化/过期清空，等待再次点击。收起/菜单清空文字和在途结果；同一会话的披露同意可以保留，但恢复不自动处理。停止/锁屏/撤权/新会话撤销同意。
- 断网撤下旧结果，恢复网络也不自动重试。已发出的服务端请求可能仍执行；撤销保证不再接受结果，不能承诺服务商撤回已收到的数据。
- 中文保留原文，无需联网。英/法→中文必须通过逐元素忠实度和全页/孤立词对照；结构正确不算翻译质量通过。
- 产品接入用服务端保管供应商密钥，APK不包含密钥。前端只使用短期、有限权限的产品凭据。供应商免费额度不等于可以公开共享密钥，也不等于KanDong后续用户全部永久免费。

## 本轮真正实现的范围

1. 独立合成实验的`OnDemandTranslation`增加可替换的`TranslationProviderChoice`：明确LOCAL/ONLINE、配置状态、模型/版本、披露版本。联网必须选中、配置可用、确认本次会话披露且网络可用才产生采集凭据；全页请求携带选定模型身份，旧/错身份响应不接受。默认构造仍仅用于标明“人工演示”的已有实验，不能用于宣布本机模型可用。
2. 当前/迟到失败、切换、断网、撤销等只改变实验状态，没有HTTP或屏幕读取器。未来实际IO适配器仍须在执行前验证凭据、支持取消并执行独立敏感过滤；本轮不是完整生产授权或过滤实现。
3. `scripts/translation_online_contract.py`准备服务商无关的纯文字请求/JSON返回契约，仅接受已固定的合成页面ID，不接受任意文字或文件。复用24页开发回归：44份外语请求（整页/仅目标对照各22）和2份中文保留结果。字段白名单不导出预期答案、scenario、包名、原始OCR候选或图像；模型输出只包含目标ID→译文/null，位置和卡片归属回绑本机源数据。
4. 请求工具只在本地生成计划，没有服务商适配器、密钥、网络调用、额度消费或真实译文结果。现有所有本地模型脚本和证据保持原样，免费候选的真实质量仍待测。

```sh

PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s scripts -p 'test_translation*.py' -v
```

输出必须是新文件，避免覆盖证据。该工具不是屏幕匿名化器；不能用于上传真实页面。真实页面必须先完成采集时效、自有镜面遮挡与敏感过滤门槛。

## 免费候选核查（2026-09-24）

| 候选 | 官方免费边界 | 对看懂的用途与限制 |
| --- | --- | --- |
| Gemini API | 部分模型有免费输入/输出，如2.5 Flash；具体限额取决于模型/项目 | 支持长上下文，可作为整屏上下文实验候选；需实际验证JSON输出和翻译。免费试验与面向用户上线的条件不同 |
