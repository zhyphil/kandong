# 整页证据与选区显示实验

2026-09-30，起点9aecfd8。独立modelprobe实验已完成“实际整页OCR → 关联结果交接 → 选区／镜面坐标”衔接，本机与专用模拟器验收通过。正式放大镜和翻译界面尚未接入，本轮未安装或操作nova 9。

## 实现行为

FullPageOcrPublication新增单次claimForRegion交接，与原publish共享消费权；仅通过原完整性、身份、正常退出和资源关闭检查的暂存结果可产生许可。许可保留同一个Guard、原metadata、取得时间与有效期，不能从旧Outcome或历史报告重新取得当前页面权利。交给控制器后，旧Pending或重复回调的清理不会撤销新拥有者。

FullPageRegionController使用单线程所有权。observePage只接收版本，不读取内容；显式click才产生本控制器的票据。生产者通过checkpoint(ticket)检查该票据，accept核对版本、点击／取得时间和原守卫。重复忙碌点击不排队，旧回调先判身份，不能误撤销新页。回调中发生收起、换页或替换后，返回前再核对世代和对象身份。

Frame保留完整原关联结果、每个文字候选的原文／来源／两个四角坐标／分数／模型及空间组。selectedIds仅表示源选区涉及的候选，contextIds保留这些候选所在空间组的全部成员，visible给出镜面可见位置；框外其他条件仍保留在整页对象中。空间组不是语义组，不自动选文字、不合并冲突、不推断语言或阅读顺序。旧CandidateContext／validOcr契约未放宽。

## 坐标规则

ROI和pan均为原图像素，镜面宽高为镜面像素。ROI先裁到原页面，倍率限制1～5，平移按现有规则限制到可视范围，然后按“源位置减去ROI起点及平移，再乘倍率”映射并裁到镜面。倍率／平移不改变源选区成员，不重新采集或识别。

当前使用文字框的包围矩形，斜框和乱序四角明确标记conservative，完整原四角仍在证据里；不声称精确字形相交。无面积的水平／垂直／斜线与点保留在整页并列为unsupportedIds，不画虚假框。仅边缘接触没有正面积时不选中。

有效空白页返回空Frame，过期或拒绝返回无Frame；空字符串候选与空白页分开。非法ROI／倍率等不返回旧画面。收起／菜单／停止撤销票据和控制器持有的结果；恢复不自动读取。原取得时间和时钟历史不重置，TTL到界、六字段版本变化、回调异常和时钟回退均拒绝。

## 实际验证

| 检查 | 结果 |
| --- | --- |
| 初始行为红灯 | 9项全部失败，含Guard回调内撤销仍返回有效的原缺陷；原9方法完整保留 |
| 退化斜线补充红灯 | 1项失败后修正；对角线有包围框面积不等于文字框有面积 |

| 专用API37／16KiB模拟器 | 94项通过，76.218秒；包括24项新共享测试、真实两页新链路、旧发布／关联／图像／原生生命周期回归 |
| 独立只读复核 | 无必须修复问题，源码／APK指纹与证据一致，只读指纹未变 |

实际固定hant-seam和blank各使用同包ImageWriter／ImageReader及已核验模型，均在两个模型会话关闭、Image释放、线程恢复后交出许可。共8次检测、16次识别，2帧／4会话／56个ORT资源关闭。繁体页16候选与同次推理逐字段一致，含“稅／税”冲突及非核心候选。

原选区4候选／4镜面框，改变倍率和平移后仍4候选但只有2框在镜面中；移框后2候选／2框。根任务用历史相同固定几何独立计算坐标、相交及组成员，结果一致；变换时原生调用和资源计数不增加。空白页实际经过原取得时间后的60005ms后撤下，没有续期或伪造时钟。旧9种原生生命周期情形一并通过。

## 运行方法与下一项

从项目根目录使用JDK17运行原有离线modelprobe单测、主／测试包构建和Lint。启动[项目专用模拟器](OCR_EMULATOR.md)并核对安装哈希后，用证据目录run-emulator.py传入--test-sha、--expected-tests 94和全新--output目录。原生测试会等待真实60秒过期，总运行约76秒；不需要屏幕共享。不要把冻结入口用于不同构件而跳过身份检查。

下一项为独立可视化实验页：展示固定整页、可调整红框、镜面位置与原文／冲突提示，接本轮控制器验证显式触发、同页复用和失效撤下。之后才继续真实语义／翻译对应与正式镜面入口；不能把原文展示或预置译文当真实翻译验收。

当前限制：真实内容变化必须由后续观察层提供正确版本或显式清理，同版本observe本身是幂等操作；真实采集、窗口归属、敏感过滤和当前帧见证未在本轮实现。控制器清理自身引用，调用方须丢弃旧Frame，不能宣称已擦除其他持有者的快照或全部堆内存。本轮也不代表OCR质量提高、真机新路径、真实翻译或产品UI通过。无真实屏幕、翻译服务、密钥、推送或发布。
