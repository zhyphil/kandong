# 翻译上下文与元素映射（设计与独立合成验证）

> 2026-10-01产品规则更新：当前开发版采用一次点击取得一张整屏快照，OCR、全文上下文翻译和镜面均绑定该快照；后续页面变化不取消或重采集，镜面明确标注“本次快照”。退出/收起/菜单/停止/锁屏/旋转或60秒过期仍清除。下文实时页面变化守卫及其合成验收保留为历史，不能作为当前开发版需求；当前实现见 [LIVE_TRANSLATION_DEV.md](LIVE_TRANSLATION_DEV.md)。

2026-09-24用户方向：获取当前屏幕整体信息形成上下文，在放大区域精准显示对应元素的翻译。本文件替代旧的“先裁选区再识别/翻译”方案；不改动已验收的原文放大手势。

## 输入与输出

**整屏负责理解，选区负责显示。** 输入是当前前台App页面的整屏可见内容，包括其标题、段落、表格/卡片、标签、按钮及相互关系。整屏指屏幕当前可见范围，不自动滚动、不读后台或屏外历史。自有辅助窗、通知、键盘不作为该页面上下文。多窗口归属不明确时先要求明确目标，不能混合不同App。

优先读取可访问树，缺少文字时按需补充本机OCR。保留可验证的角色、图标文字描述及结构关系；不能识别的图片、图标或关系标为未知，不假设OCR能理解全部视觉信息。以来源和实际覆盖范围标记完整性，不能只因获得一张截图就声称完整。

输出仍在看懂镜面内：选区命中的元素携带相关上下文翻译，按原文位置对应显示。原App布局、按钮与事件不变。保留原文切换和原文关联；译文更长时允许镜面内语义组卡片，不能缩小到无法阅读或覆盖到另一按钮上。

首版分别处理单一EN、FR或ZH页面，混排已按用户最新要求移出当前测试及验收门槛。单语页可结合完整页面证据确定源语言，短按钮无需单独达到语言分类分数门槛；证据不足仍标不确定。翻译必须利用整屏可见上下文，按目标元素/组ID返回结果；EN/FR译为中文，ZH保留原文和元素绑定。当前合成实验不代表真实译文或提取质量通过。当前执行顺序见[SINGLE_LANGUAGE_TRANSLATION](SINGLE_LANGUAGE_TRANSLATION.md)。

## 数据契约

| 对象 | 必需信息与约束 |
| --- | --- |
| ScreenContext | sessionId、snapshotId、pageGeneration、采集时刻、目标display/window、方向/尺寸/坐标基准、内容变更标记、覆盖范围与缺失原因；不把不同页面的树和像素合并 |
| ContextBlock | 快照内唯一blockId、原文、语言、tree/OCR来源、角色、原始bounds/可见bounds、阅读顺序、groupId/父子/标签关系、截断/识别置信信息；未提供的置信度记未知 |
| SemanticGroup | 同一段落、价格卡片或表格行等有依据的分组，关联标题、单位及条件的blockId；空间接近本身不证明语义归属，歧义保留 |
| RegionSelection | 当前snapshotId、selectionGeneration、源区矩形；倍率/镜面偏移另存为显示变换，不改变文字含义 |
| TranslationRequest | 页面版本、完整可见页面快照（全部块、组、角色、位置、完整性）、目标块/组ID及原文、关联上下文ID、单语页源语言证据、目标语言、候选模型版本；上下文选取要可追溯，不能无提示截掉关键限制 |
| ElementTranslation | 对应的源blockId/groupId、原文、译文、依据上下文ID、快照及语言/模型版本、错误/缺失；未知ID、重复ID、漏项和失效版本不能直接上屏 |
| TranslationLayout | 当前选区版本、源元素可见范围到镜面的映射、译文布局范围；来源几何和译文排版分开，不能用译文字数猜原文坐标 |

树与OCR按几何和内容去重；冲突保留来源并标记不确定，不默默改写金额/日期/否定。blockId仅在同一快照内稳定，翻页后不能把同位置或同文本当同一元素。正文、contentDescription、可见标签重复时避免重复翻译。过滤敏感内容后才形成可交给模型的上下文。

完整可见语义组参与翻译，即使红框只切到半句。屏外缺失的半句不能补全。某组的标题/条件可能不在框内，但必须属于同组；价格与日期原值及所属对象需可核对。译文对照卡可以展示必要上下文，不把解释或推断混入原文字段。

## 获取快照与模型要求

用户点击镜面工具栏“翻译”按钮后才启动本次当前页文本处理。打开应用、打开放大镜、移框、缩放或恢复悬浮窗均不自动启动OCR/语言识别/翻译。整屏识别不能沿用当前先裁ROI的像素输入；当前compat依然只做局部画面放大，没有这一能力。新流程须分段测量整屏读取、OCR、翻译、映射的耗时与峰值内存，结束/取消可靠释放。

自有FLAG_SECURE镜面可能遮住屏幕内容，排除自有树节点并不能还原其后像素。待验证方案是在一次刷新中短暂隐藏自有辅助窗、等待符合当前页面状态的新帧、采集后恢复；等待帧的期间也必须尊重收起/菜单/终止状态，不能强行恢复已关闭窗口。树与像素非原子同步，需校验窗口/几何/内容版本；无法确认时重取或提示缺失，不拼接旧帧。

不绕过第三方安全窗口，不从隐藏窗口补采。当前屏幕内容被其他窗口遮住时按缺失处理。单独的OCR实验成功不证明全屏可读、语义分组或位置映射成功。

模型必须能利用相关页面上下文，并可靠返回对应源元素/语义组的译文。ML Kit当前公开示例输入字符串、返回译文字符串；据此不能推定具备结构化页面上下文或元素对齐能力。[官方Android接入](https://developers.google.com/ml-kit/language/translation/android)。候选仍未选定，应先验证组级翻译、上下文利用及对应关系，再评估是否需更强的本机模型；不能把整屏译文按顺序机械切回原框。

## 刷新与失效规则

| 事件 | 上下文/翻译处理 |
| --- | --- |
| 同一有效页面内移动/调整红框 | 复用短时整屏上下文；重新选择目标元素。本次页面结果按当前选区投影；移框不发起新的屏幕读取；不因选区变化重做整屏OCR |
| 双指缩放、滑杆、镜面平移 | 仅改变显示映射；源元素不变，不重新翻译 |
| 滚动、切页、内容/窗口/布局变化或快照过期 | 立即撤下旧译文，失效旧上下文及在途请求；等待用户再次点击“翻译”，然后取得新快照；不自动重采集或重新翻译，不默认持续全屏OCR |
| 收起、菜单、显示原文 | 停止文字处理，清空上下文/译文并拒绝迟到结果；保留已验收的几何/倍率恢复规则。再次使用需主动点击“翻译”并取得新快照 |
| 锁屏、旋转、撤权、会话结束 | 沿现有终止路径结束，清空图像/文本/任务；不自动重开 |
| 来源不完整、版本不能确认、对应关系歧义 | 撤下相关译文并保留原文，提示未识别/需刷新；不能拿旧结果填空 |

一次点击仅批准当前页面的处理；结果和上下文均有时效，忙碌时不叠加排队，取消后迟到采集/译文都失效。显示原文可以终止本次文字处理。缓存仅在本次有效页面内按源ID、上下文版本、目标语言及模型版本复用。迟到结果只有在页面仍有效时才可进入当前缓存，呈现必须按最新选区重算；旧回调不能写回旧选区布局。页面变化检测、过期阈值与自动刷新节流均待实测；若无法可靠确认更新，就显示待刷新状态，不继续把旧译文贴在实时画面上。

## 合成场景验收矩阵

下表定义验收范围。独立[合成上下文实验](CONTEXT_LAB.md)已验证手工元数据下的上下文传递、绑定、几何与失效；真实提取/分组、模型翻译、受保护窗口及跨App能力尚未验证。原有12条单句和37项OCR证据保持原样，新增[华为OCR验证](HUAWEI_OCR_VALIDATION.md)保留单位等关键识别失败。

| 场景 | 必须证明 |
| --- | --- |
| 单一英语、单一法语、单一中文页面，中文简体/繁体分列 | 分别验证整屏提取与上下文译文；中文保留原文，英法译文对应原块；结合整页理解短词，金额/单位/条件不跨卡片串用；混排不纳入当前门槛 |
| 同屏两张房价卡：不同价格、每晚/总价、取消条件，红框只含价格 | 框外标签参与上下文，金额/单位/限制归属正确，不能跨卡串用 |
| 订房页面与书店页面分别含Book | 利用明确页面上下文区分预订与书籍，保留各自源元素ID |
| 两张卡片均有Continue，且条件不同 | 同词各有独立ID/语义组，不能以文本相同合并或交换译文 |
| 红框切中Non échangeable et non remboursable | 用当前可见完整语句翻译，两个否定不漏；真正屏外部分标缺失 |
| 同页拖框、改大小、1～5倍与镜面平移 | 上下文可复用，元素选择/几何正确；倍率不改变译文含义 |
| 原位价格更新、滚动后相同坐标、旧请求迟到 | 旧页面结果不上屏，同位置或同文字不导致串页 |
| 自有镜面遮挡、树缺字、OCR重复/冲突、仅图标 | 缺失/未知有标记，不能自造整屏完整性或虚构按钮含义 |
| 译文超长、菜单/收起期间完成、锁屏再回来 | 可读卡片与源组明确关联，已停止任务不能显示结果或恢复窗口 |

先分别判定提取正确、上下文利用、翻译忠实和几何映射，再记录性能；任一关键金额/否定/条件错误单列失败，不能用平均分掩盖。随后再做目标华为和真实App人工验证，真实页面不写报告原文或截图。产品状态与任务跟踪见[任务板](../TASKS.md)。
