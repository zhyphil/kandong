# 本机画质对照实验

状态：独立实验，不进入v0.1.0正式放大镜。目标是比较阅读效果与计算成本，不承诺把截图恢复成真实高清。

## 范围与数据

- 独立Android应用 `qualitylab` / `com.kandong.qualitylab`，显示名“看懂画质对照”。最低API29，沿用现有Kotlin/JDK/Gradle与JUnit，无新增运行时依赖。
- 没有网络、屏幕共享、悬浮窗或无障碍权限；不连接`compat`服务。不需要卸载现有看懂，签名互不影响。
- 唯一输入是本机绘制的320×160像素固定中文样本，包含易混淆字、数字/小数点、浅灰小字、彩色边缘和深色背景。不是用户页面或OCR重绘。
- 每次生成只在应用私有目录保存这张**合成图**及其2/3/5倍对照；主动测量时保存毫秒结果、设备型号/API，不保存序列号。没有上传。真实放大镜仍保持不保存页面的规则。
- 1～5倍连续滑杆、直接拖框、双指缩放和收起等正式交互保持原样。实验页的2/3/5按钮只用于重复对照。

## 三条处理路径

| 对照 | 实现 | 要观察的问题 |
| --- | --- | --- |
| A 当前平滑 | Android Canvas + FILTER_BITMAP_FLAG的双线性插值 | 作为现有放大采样方式的近似视觉基准；不是直接测量现有GPU镜面 |
| B 精细平滑 | 独立实现Mitchell–Netravali双三次重建，B=C=1/3，分离式4+4抽头 | 锯齿是否减少，同时检查细字有无变软、浅灰笔画消失 |
| C 平滑 + 轻度锐化 | 源图3×3高斯模糊差分，强度0.2，单通道改变量最多12/255，再用B放大 | 笔画对比是否更易读，同时检查白边、粘连和颜色边缘 |

像素中心对齐、边界夹取、权重归一化；1倍旁路不修改像素。当前处理只支持不透明ARGB合成图，上限51,200源像素/1,280,000输出像素。这个CPU实验不能直接用于任意大小的实时屏幕区域，也未覆盖透明/HDR/广色域。

图片没有二次适配缩放：Bitmap密度设为NONE，绘图视图按实际像素尺寸测量，宽度超出屏幕时左右滑动。三组图片使用同一源图、倍率和显示方式。任务在单个后台线程串行执行，切换倍率/离开页面取消旧任务，并阻止迟到结果覆盖新结果。

## 构建与运行

```sh
cd /Users/haoyuzuo/Projects/KanDong
JAVA_HOME=$(/usr/libexec/java_home -v 17) ./gradlew :qualitylab:testDebugUnitTest :qualitylab:assembleDebug :qualitylab:lintDebug
```

APK：`qualitylab/build/outputs/apk/debug/qualitylab-debug.apk`。Android Studio选择`qualitylab`运行；或在明确指定设备后安装：

```sh
adb -s <目标设备序列号> install -r qualitylab/build/outputs/apk/debug/qualitylab-debug.apk
adb -s <目标设备序列号> shell am start -n com.kandong.qualitylab/.QualityLabActivity
```

1. 打开“看懂画质对照”，无需开启任何权限。
2. 默认3倍。向下比较A/B/C；左右滑动看完整宽度，再试2倍和5倍。
3. 特别检查“未/末、日/目、己/已”和1028.50中的小数点。记录最容易读的一组，而不是只看轮廓是否更锐。
4. 点“测处理耗时”。每组预热2次，轮换顺序执行9轮，显示中位数与P95（9个样本的P95就是最大值）。这只包含CPU处理与输出Bitmap创建，不含屏幕采集、显示、PNG写出。
5. 切换到后台即取消处理；返回后可重新生成/测量。静态看图本身不能测出实时放大镜的额外耗电。

初步视觉观察：B/C在部分边缘上更连续，C略微加强笔画，但不是文字细节恢复；灰色小字仍受原始采样限制。该段为模拟器初步观察，后续目标真机的3倍偏好见下节。CPU路径在高倍率下的处理成本明显增大，**当前不建议把本实验直接放入实时镜面或默认开启**。

## 真机阅读与后续门槛

- 没有证明净收益前保留v0.1.0效果，不新增云端、模型下载、收费接口或自动启用“高清”标识。

## 来源与归属

- Android官方[Paint.FILTER_BITMAP_FLAG](https://developer.android.com/reference/android/graphics/Paint#FILTER_BITMAP_FLAG)：双线性采样；它不能创造原图缺失的细节。
- Mitchell, D. P. & Netravali, A. N. (1988), *Reconstruction Filters in Computer Graphics*, SIGGRAPH / Computer Graphics 22(4), 221–228，[原论文](https://www.cs.utexas.edu/~fussell/courses/cs384g-fall2013/lectures/mitchell/Mitchell.pdf)，公式(8)，参数B=C=1/3。只参考公开数学定义，未复制第三方实现、论文图像或模型。
- 轻度锐化、样本文字、图标与对照界面为项目内实现。它们都是本机图像计算，不依赖外部服务；仍然存在计算与电池成本。
