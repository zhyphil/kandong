# OCR 平滑预处理候选 · 2026-09-24

结论：实验实现与双设备验证完成，但**不采用为统一 OCR 预处理**。部分英法文字改善，同时出现新的中文单位和错字。三语识别质量仍未验收，正式放大镜没有加入此处理。

## 可复现的处理

独立“看懂文字实验”增加“开始144项平滑对照”。18个既有输入 × 原生/固定PNG × 2/3倍 × Latin/Chinese，总计144项。原图/最近邻144项及最早37项均保留。每个模型处理全部输入；期望文字和语言标签只用于事后评分。

bilinear-center-integer-v1 使用像素中心对齐、边缘钳制、四角整数权重，两个轴合并后一次四舍五入；不依赖 Android Bitmap 默认采样。输入必须完全不透明，维度上限2048、像素上限400万；实际送入模型的像素重新取指纹。原图/处理图/还原坐标及算法身份均记录，比较规则不变。

## 检查与真机结果

- 先以占位实现跑出4项行为断言失败，再实现插值；6项像素回归加1项完整矩阵回归，最终44项JUnit全部通过。构建通过，Lint 0错误/17提示，签名和16KiB对齐通过。固定语料、全部30个模型资产及103个受保护原文件不变。
- 最终APK 53,271,300 bytes，SHA256 947493917cab4f5f8325d79b004455be7518dc59a9a4c32c0bcb1c78f72ceb89。华为实际安装包指纹一致；仅自身签名权限，无联网/采屏权限，内部实验入口不导出。没有改系统安全/网络设置；未做本轮断网测试。
- 华为LIO-AN00/API31与专用API36各完成144项及清理后重开144项；重复的文字、块位置与像素一致。72个固定PNG处理任务在两设备上像素及原文一致。
- 两设备取消、切后台返回不自动运行、双向跨实验取消及清理后重开通过；华为取消/后台都命中在途任务。API36另做旋转取消并恢复原设置。原37项结果保持各自旧基线；新APK另外跑API36原144项，文字/块/像素均不变。

## 质量决定

华为英法样本中kg得到保留，一些sans错误改善，但n'est仍丢撇号。中文同时发生公斤→公厅、退款→返歉、不含税→不合税；不同倍率之间也不稳定。繁体32px有改善，但不能据此忽略小字和混排。

各处理组仅3～7/17张文字图严格匹配，固定PNG两设备结果相同；空白负例正确。严格不匹配含空格/标点差异，不等同于每项语义错误；反过来，关键单位/错字也不能按“只是格式”放行。这是小型难例集，不代表一般准确率。

下一任务：在相同固定像素上筛选另一种本机OCR引擎（Tesseract），先做宿主机质量筛选，再决定是否进入Android工程验证。宿主机结果不能代替华为的性能、兼容、生命周期或最终阅读验收。不得按预期答案选择模型或修正文案。
