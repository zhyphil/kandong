# 核心交互基线 · v0.1.0

用户在目标华为确认“三个操作都正常”后，明确要求固定核心并制作Release。已验收的行为源码基点为 `6b36652`；v0.1.0只调整版本和发布配置，不更改运行交互。

必须保持：红框内部/边框直接拖动；固定右上角小角柄独立调宽高；选区和倍率互不影响；镜面双指1～5倍缩放、数字/滑杆同步，新会话2倍；单指平移；镜面自动上下避让；收起/菜单暂停、恢复原选区/倍率/偏移；全屏菜单；关闭/锁屏/旋转清理；本机处理、无网络、无自动操作。

后续翻译/解释应围绕此基线增加能力。用户没有明确调整交互时，不恢复移动图标、框内触摸穿透、固定2/3/4按钮、框大小绑定倍率或手动换边。实质改变先说明原因，并对照41项现有兼容逻辑回归及设备验收步骤核对。

这个标签表示已确认的核心版本，不表示全部机型/应用或完整MVP已经验收。证据范围见[VALIDATION](VALIDATION.md)。
