# 条件范围不明时的整页原文保护

2026-10-01，基点 `701e2b9`。独立实验增加显式启用的 `conditionGuard`：英语/法语页面包含退款文字，又出现有限的前提、否定、例外或限制提示时，**本次整页保留原文，不发送该页翻译目标**。它拦住了上一轮7个不完整目标，普通完整句仍可请求。这个保守策略会误拦无关内容，只验收为可选实验防护，未采用为默认翻译方案。

## 实现范围

`FullPageConditionGuard` 复用原v1派生布局，不改原候选、文字、分数、来源、空间关联诊断或完整context。由于尚不能可靠确定修饰范围，触发时阻断整页，包括没有提示词的后续碎片。保留全部原文与来源供展示，不猜测新的完整译句，也不挑选重复来源中的赢家。

这是有限词汇风险检测，不是通用语义完整性判断：仅覆盖英语/法语退款页，检查诸如 except/unless/only/if/not/required 与 sauf/si/condition/réserve/pas/sans 等提示。检查时处理大小写、重音与空格，但不改写保存的原文。标准双行句头自身的否定已在组内，不触发额外拒译。未列出的表达、OCR错字、屏外条件及非退款主题不保证识别；中文仍保留原文。

适配器/按需协调器新增 `conditionGuard=false` 参数，必须与 `grouped=true` 显式一起使用。默认v1路径不变。新模式具有独立页面身份、块/组身份及布局版本 `full-page-condition-guard-v1`，覆盖原因标明保护范围。旧录制即使文字相同也不能绑定到新模式。原取得时间、60秒期限、取消/菜单/收起/页面变化及迟到回复规则继续生效。

正式放大镜、独立实验UI和供应商执行均未接入此开关。没有设备安装、新OCR推理、真实屏幕读取、凭据访问或供应商调用。
