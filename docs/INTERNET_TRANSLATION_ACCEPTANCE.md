- 开发版沿用英语/法语 → 开始翻译 → 整屏本机 OCR → DeepL → 本次快照镜面。

- 不接入登录、订阅或支付，不变更 v0.1.0 放大手势；release 仍仅本机放大。
- 部署、真实供应商验证、设备试用分别记录，未执行的项目不勾选。

## 云端与手机验证

1. 核对部署版本和实际 HTTPS 地址；只为当前测试机配置独立访问凭据，不将 DeepL 密钥放入 APK。
2. 更新目标手机并核对构件；清除该手机的 `tcp:18741` USB 反向转发，关闭本次 KanDong localhost relay。不得停止其他进程。
3. 先做不含页面内容的联网健康检查，单独记录其结果。此项不算真实翻译验收。
4. 用户亲自确认本次共享。在 Garden Hotel 公开英语页点翻译、选择英语、开始翻译，检查镜面对应内容；法语页同样验证。系统权限和真实页面开始按钮不代点。
5. 拔下数据线，保持手机 Wi-Fi 或移动数据，再翻译一页。用户确认成功后，才可记录“拔线可用”；若需要读运行数字，重新连接只读取数字，不能将重新连接后的结果当作拔线证据。
6. 测试断网提示、重新联网后手动开始、取消/收起后不发布迟到结果；上一份成功结果须保留，联网恢复不能自动重新发送页面。
7. 成功结果停留超过两分钟仍可阅读，全文与返回正常；新翻译成功才替换，失败/空页不替换。收起恢复/菜单返回保留快照和手势。点“实时”回到当前画面；锁屏/停止/撤销/旋转清除全部结果。处理中的请求仍最多60秒，不能把这个时限当作阅读期限。

服务健康、合成翻译、真实页面翻译及用户主观译文质量必须分列。不要将旧版英法页面的认可套用到新云端路径。
