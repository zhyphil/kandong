# 合成整屏上下文实验 · 2026-09-24

状态：独立实验实现、30项单元测试、Android构建及专用API36界面验证完成。位于ocrlab，**没有接入正式放大镜、真实页面采集或翻译模型**。语义分组和中文都是人工编写的测试材料。

## 已实现的范围

- 保留当前合成整屏块与显式语义关系；红框只选择目标，同卡片的标题、单位、条件可在框外参与请求。已知属于不同卡片的直接关联会被拒绝。
- 用源ID及所属组区分重复文字，冻结请求与输入集合；未知、重复、遗漏或绑定不符的响应整批拒绝。结构校验不判断中文含义是否正确。
- 同页移框复用上下文与有效缓存，按最新选区和倍率/平移呈现；页面替换、暂停、菜单、停止、过期及取消撤销旧请求的发布资格。
- 未识别、仅图标、遮挡、截断、缺失成员或归属歧义保留原因，不生成猜测译文。完整可见语句可跨越红框；真正缺失的半句不补造。
- 源锚点与可读中文卡片分别绘制。输入坐标已归一到同一未缩放合成屏幕；真实Android窗口、旋转、Insets和截图映射没有在此验证。

7个预置页面包括两张房价卡、重复Continue、酒店Book、书店Book、法语完整否定句、缺失半句和不完整证据。示例“您不能不付款”等中文只来自固定表，不来自模型。实验限制为单页128块、64组、8个在途请求，快照有效期60秒；这些是实验边界，不是生产参数结论。

## 发现与修复

主任务额外构造A价格直接关联B取消条件的错误输入，先实测回归失败，再拒绝跨组关联；原全局标题只取直接关系，不经标题继续遍历其他卡片。最终30项通过。

独立只读审查发现1项P2：绘图恰好触发过期后，定时刷新可能因快照已空而跳过，留下旧文字。现改为绘图只消费已生成的显示结果，定时刷新统一更新文字、待交付请求和绘图，空状态也刷新。主任务复核差异并完成实际过期检查；没有声称在设备上确定性复现旧帧边界竞态，也没有声称独立审查重跑于修复后版本。[原审查](evidence/context/2026-09-24/review.md)、[处理记录](evidence/context/2026-09-24/review-resolution.json)。

界面验证脚本最初假设返回实验应用一定回首页，并对Activity切换作了过早断言。核对实际任务返回行为后改为等待页面切换及完成后台生命周期，再重跑通过；这些脚本问题没有作为产品失败或通过证据隐藏。

## 运行

使用项目JDK17，执行：

~~~sh
./gradlew :ocrlab:testDebugUnitTest :ocrlab:assembleDebug :ocrlab:lintDebug
~~~

安装ocrlab的debug APK，打开“看懂文字实验”→“合成上下文与映射实验”。按“载入”→“提交演示请求”→移动ROI预设→“交付人工预置结果”，可观察迟到结果与当前选区的对应关系；也可调倍率、平移、清空和切换场景。页面顶部始终说明人工预置及无模型；离开后不自动载入。原37项OCR仍通过原按钮启动。

[控制页截图](evidence/context/2026-09-24/context-controls.png)、[过期后截图](evidence/context/2026-09-24/context-expired.png)均仅含合成材料。模拟器验证结束后已停止实验进程并关闭本项目专用AVD。
