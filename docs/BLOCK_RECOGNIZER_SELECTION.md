# 按块模型筛选的回顾性评估

2026-09-24：评估完成，候选未通过整体质量门槛，不接入 Android 或正式放大镜。

## 固定规则与范围

规则在本地提交 e123c55 预先记录：只配对行数和几何完全相同的块；中文候选含汉字则原样保留，否则 Latin 候选含拉丁字母则原样保留；证据不足待核对，块无法配对则不输出。选择函数只接收两段候选文字，不接收源答案、语言标签或模型分数。字形不是可靠的语言判断。

脚本只分析已有合成报告：五张已验收手机图片及历史49张宿主图片的1/2倍结果，共103组配对。没有新增手机测试、模型推理或真实页面采集。十项规则防护检查通过，两轮JSON逐字节一致。

## 结果

整页准确按既有 NFC＋Unicode 空白规则判定；无法配对或需核对均计入未准确输出，不能从分母删去。

当前结果证明，对两个最终输出列表直接按行配对的候选不能采用。行数或几何不同的具体原因尚待核查，不用近邻或已知答案强行补配。后续应在共同检测框身份基础上保留两个模型的原始输出，再进行独立评估；仍需新的冻结语料验证。
